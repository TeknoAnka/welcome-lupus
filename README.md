# LupuS Hello

LupuS Hello is a simple hello world application built with Rust and Tauri.

## 🛠️ Prerequisites

- **Rust & Cargo** (`>= 1.75`)
- **Tauri v2 CLI** (`cargo install tauri-cli`)
- **System Libraries (Linux)**: `pisim`, `pisidi`, `kaptan`, `alacritty`, `dns-changer`

---

## 🚀 Building & Install

```bash
# 1. Clone Repository
git clone https://github.com/Antolun/lupus-hello
cd lupus-hello

# 2. Start Build
chmod +x ./build-pisi.sh
sudo ./build-pisi.sh

# Install Package
sudo pisi it ./lupus-hello-*-x86_64.pisi
```
